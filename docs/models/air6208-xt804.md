# Air6208 / XT804 / Air101 / Air103

## 适用型号

- Air6208
- xt804
- Air101 / Air103 / Air601

## 推荐命令

```bash
# 全量刷机
luatos-cli flash run --soc firmware.soc --port COM7

# 刷脚本区
luatos-cli flash script --soc firmware.soc --port COM7 --script lua/

# 文件系统分区操作
luatos-cli flash clear-fs --soc firmware.soc --port COM7
luatos-cli flash flash-fs --soc firmware.soc --port COM7 --script lua/

# 二进制日志
luatos-cli log view-binary --port COM7 --baud 2000000
```

## 说明

- XT804 系列支持完整分区操作（脚本、FS、KV）
