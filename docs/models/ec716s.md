# EC716S / Air780EL / Air780ET

Air780EL 与 Air780ET 固件通用，本次实机为 Air780ET，测试文件名为 `AirM2M_780EL_V1001_LTE_AT_TU.binpkg`。

## 刷机

```powershell
luatos-cli flash run --binpkg "AirM2M_780EL_V1001_LTE_AT_TU.binpkg" --port auto
```

`--binpkg` 是 `flash run --soc` 固件参数的别名，以 `.binpkg` 扩展名识别输入；不能同时指定两个参数。裸包当前只开放 `EC716S_PRD` 产品，校验镜像哈希和分区后才进入下载模式。

先关闭 LuaTools、串口助手等占用设备的软件。程序自动向命令口发送重启下载指令，等待 `17D1:0001` 下载口。若自动切换不成功，请按住 BOOT 复位，出现下载口后释放 BOOT 并重试。

该入口用于 AT 固件，不支持 Lua `--script` 覆盖、`--tail-log-secs`、`--baud` 或 `--rts-reset`。裸 binpkg 不支持 `flash script/test`；烧录后通过 AT 响应检查运行状态。

## 运行验证

本次固件 USB 接口 2 为 AT 命令口（Windows COM3），接口 4 为二进制诊断日志（COM4）。不要按 COM 号大小判断用途，也不要把 LuatOS 的用户虚拟串口接口 6 当作这份 AT 固件的 AT 口。

以 115200 打开 COM3，依次发送：

```text
AT
ATI
AT+CGMR
```

实测 AT 返回 `OK`，版本查询返回 `AirM2M_780ET_V1001_LTE_AT_TU`。文件名包含 EL 而版本返回 ET 是该通用固件的正常表现。

参考 [EC716S 刷机协议](../ec716s-flash-protocol.md)。
