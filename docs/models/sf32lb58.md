# SF32LB58

## 适用型号

- sf32lb58
- air8101-sf32

## 推荐命令

```bash
# 全量刷机（手动进入 ROM BL）
luatos-cli flash run --soc firmware.soc --port COM13

# 全量刷机（CH340X 自动复位）
luatos-cli flash run --soc firmware.soc --port COM13 --auto-reset

# 高速刷机（硬件支持时）
luatos-cli flash run --soc firmware.soc --port COM13 --auto-reset --baud 3000000

# 脚本区刷写
luatos-cli flash script --soc firmware.soc --port COM13 --script lua/ --auto-reset

# 文本日志
luatos-cli log view --port COM13 --baud 1000000
```

## 说明

- `--auto-reset` 依赖 CH340X 增强 DTR 改装硬件
- 不支持 `flash clear-fs` 与 `flash flash-fs`
