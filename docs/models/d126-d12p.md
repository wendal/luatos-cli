# D126 / D12P（ArtInChip）

D126 是匠芯创 d12p 平台，启动链和烧录协议与 Air/EC/BK 模组不同：升级口不是串口，
而是 VID `0x33C3` / PID `0x6677` 的厂商自定义 USB Bulk 设备。luatos-cli 直接实现
AIC 升级协议（CBW/CSW + `UPGC`/`UPGR` 命令头），不依赖 luban-lite 的 `upgcmd`。

## 固件包

LuatOS/D126 的 `.soc` 命名为：

```text
LuatOS-SoC_V0001_D126_1.soc
```

- `V0001` 来自 BSP 的 `LUAT_BSP_VERSION`
- 固件类型号为 `1`
- 包格式为 ZIP，内含 `info.json`、`luat_conf_bsp.h`、`d12p.elf`、`d12p.map`、
  `d12p.bin`、`d12p_os.itb`、`script.bin`、`bootloader.bin`、`bootloader.aic`
  和完整 AIC 镜像

## info.json

D126 在通用字段之外增加了 A/B 脚本槽：

```json
{
  "version": 1,
  "chip": { "type": "d12p", "ram": { "total": 16384, "sys": 2048, "lua": 512 } },
  "rom": {
    "file": "d12p_d126-demo124-nor_v1.0.0.img",
    "fs": {
      "filesystem": { "offset": "c00000", "size": 1024, "type": "lfs" },
      "script":     { "offset": "d00000", "size": 1024, "type": "luadb" },
      "script_r":   { "offset": "e00000", "size": 1024, "type": "luadb" },
      "kv":         { "offset": "f00000", "size": 64,   "type": "fskv" }
    },
    "version-core": "v0001",
    "version-bsp": "V0001",
    "mark": "default"
  },
  "script": {
    "file": "script.bin",
    "lua": "5.3",
    "bitw": 64,
    "use-luac": false,
    "use-debug": true
  },
  "user": { "project": "d126-demo124-nor", "version": "1.0.0", "log_br": "115200" },
  "download": {
    "bl_addr": "0",
    "app_addr": "100000",
    "app1_addr": "400000",
    "script_addr": "d00000",
    "script1_addr": "e00000",
    "fs_addr": "c00000",
    "fskv_addr": "f00000",
    "nvm_addr": "0",
    "force_br": "115200"
  }
}
```

约定：

- `offset` 为不带 `0x` 的十六进制；`size` 单位为 KiB
- `script_r`、`app1_addr`、`script1_addr` 是 D126 的 A/B 扩展字段
- `script.bitw=64`（`LUAT_CONF_VM_64bit`），`use-luac=false`（脚本区只存源码）
- `data` / `fskv` 是运行期分区，完整固件镜像不写入它们

## 分区

| 分区 | 偏移 | 大小 | 用途 |
|------|------|------|------|
| `spl` | `0x000000` | 512 KiB | Bootloader |
| `os` / `os_r` | `0x100000` / `0x400000` | 3 MiB | OS A/B |
| `data` | `0xC00000` | 1 MiB | LittleFS `/data` |
| `scripts` / `scripts_r` | `0xD00000` / `0xE00000` | 1 MiB | luadb A/B |
| `fskv` | `0xF00000` | 64 KiB | LittleFS KV |

## 烧录

进入升级模式：按住 BOOT 键上电，`lsusb` 出现 `33c3:6677` 即可。Linux 需要 udev 规则：

```udev
SUBSYSTEM=="usb", ATTR{idVendor}=="33c3", ATTR{idProduct}=="6677", MODE="0660", GROUP="uucp"
```

```bash
# 全量烧录：Stage 0 自动下载 updater，设备重新枚举后继续写应用分区
luatos-cli flash run --soc LuatOS-SoC_V0001_D126_1.soc --port auto

# 全量烧录 + 覆盖应用脚本（corelib 自动从 .soc 的 script.bin 保留）
luatos-cli flash run --soc LuatOS-SoC_V0001_D126_1.soc --script ./lua --port auto

# 只烧脚本分区（从 .soc 取 script.bin）
luatos-cli flash script --soc LuatOS-SoC_V0001_D126_1.soc --port auto

# 只烧脚本分区，并合并 ./lua 目录
luatos-cli flash script --soc LuatOS-SoC_V0001_D126_1.soc --script ./lua --port auto

# 只烧脚本分区（指定完整 luadb 镜像，需自行包含 corelib）
luatos-cli flash script --soc LuatOS-SoC_V0001_D126_1.soc --port auto --bin script.bin
```

`--script` 的合并规则：只保留 `.soc` 内 `script.bin` 的三个 corelib
（`sys.lua` / `sysplus.lua` / `libnet.lua`），其余条目全部来自给定目录。

生成带新脚本的 `.soc`（同时更新 `script.bin` 和 AIC 镜像组件及 CRC）：

```bash
luatos-cli soc inject-scripts --soc LuatOS-SoC_V0001_D126_1.soc --script ./lua -o D126-custom.soc
```

运行期分区（`data` / `fskv`）：

```bash
# 用目录内容生成 LittleFS（4 KiB 块）并写入 data 分区
luatos-cli flash flash-fs --soc LuatOS-SoC_V0001_D126_1.soc --script ./data --port auto

# 清空 data 分区（写 0xFF，下次启动自动格式化）
luatos-cli flash clear-fs --soc LuatOS-SoC_V0001_D126_1.soc --port auto

# 清空 fskv 分区（写 0xFF）
luatos-cli flash clear-kv --soc LuatOS-SoC_V0001_D126_1.soc --port auto
```

`data` 分区为 1 MiB LittleFS（块 4 KiB、页 256 字节），`fskv` 为 64 KiB
LittleFS KV。清空后运行期只在分区全 0xFF 时自动格式化，不会覆盖已有数据。

分区读回（只读，不需要 `--force`）：

```bash
luatos-cli flash dump --soc LuatOS-SoC_V0001_D126_1.soc --port auto --partition scripts -o scripts.bin
luatos-cli flash dump --soc LuatOS-SoC_V0001_D126_1.soc --port auto --partition data -o data.bin
```

D126 只支持按 MTD 分区读，不支持 `--addr/--len`；可用分区名由 bootloader 的分区表
决定（`spl`、`env`、`os`、`os_r`、`data`、`scripts`、`scripts_r`、`fskv` 等）。

`--port` 对 D126 表示 USB 选择器：可省略、填 `auto`，或填 `bus:port`
（如 `1:2-4-2`，即 `lsusb` 的总线号和 hub 端口链）。现场有多个 D126 时必须指定。
烧录完成后 CLI 会执行 U-Boot `reset` 让设备重启。

`flash script` 支持冷启动：设备处于 Boot ROM 阶段时，CLI 会先用 `.soc` 里的
`image.updater.*` 把设备带到 U-Boot 阶段，再写 `scripts` 分区。因此按住 BOOT
上电后可以直接烧脚本，不需要先做一次全量烧录。

## 命令

```bash
luatos-cli soc info LuatOS-SoC_V0001_D126_1.soc
luatos-cli soc files LuatOS-SoC_V0001_D126_1.soc
luatos-cli soc unpack LuatOS-SoC_V0001_D126_1.soc -o d126_soc
```

`soc info` 会打印 `App1 Addr`、`Script1 Addr` 和 `Script B` 分区：

```text
  Chip:       d12p
  BSP:        V0001
  Script Addr:d00000
  Script1 Addr:e00000
  Script B:   0x00E00000  (1024 KB)
  FS Addr:    0x00C00000  (1024 KB)
  KV Addr:    0x00F00000  (64 KB)
```

## FOTA

D126 使用 LFTA 包（`LFTA` + 256 字节头 + part 数据），CLI 可直接生成：

```bash
# 脚本 + app
luatos-cli fota build --new LuatOS-SoC_V0001_D126_1.soc -o d12p_fota.bin

# 仅脚本
luatos-cli fota build --new LuatOS-SoC_V0001_D126_1.soc --script-only -o d12p_script_fota.bin
```

part 0 取自 `.soc` 的 `script.bin`，part 1 取自 `*_os.itb`；设备端按
`osAB_now` / `scriptsAB_now` 写入非当前槽。D126 不支持差分 FOTA，`--old` 会被拒绝。

## 限制

- 已支持 `flash run` / `flash script` / `flash-fs` / `clear-fs` / `clear-kv` /
  `flash dump --partition`；`flash raw`（任意地址写）、`flash test`、`flash-res`
  尚未实现。
- `flash run --script` / `soc inject-scripts` 以 `.soc` 内已有的 corelib 为基准，
  无法替换 `sys.lua` / `sysplus.lua` / `libnet.lua` 本身。
- D126 USB 烧录不使用 `--baud` / `--rts-reset` / `--tail-log-secs`；日志走设备
  独立的 UART0（115200 8N1）。
- `.soc` 内的完整 AIC 镜像仍是实际烧录依据；`info.json` 用于版本/分区清单。
- Windows 上厂商自定义 USB 设备需要先绑定 WinUSB 驱动（安装 AiBurn 驱动或使用
  Zadig）；Linux 只需上面的 udev 规则。

## 脚本镜像命名

D126 和其他平台一样，从 `info.json` 的 `script.file` 读取脚本镜像名，SDK 统一为
`script.bin`（内容仍是 LuatOS LuaDB/Luadb 格式）。CLI 一律使用 `info.script.file`，
不硬编码文件名。
