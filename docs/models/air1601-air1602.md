# Air1601 / Air1602 / CCM4211

## 适用型号

- Air1601
- Air1602
- CCM4211

## 推荐命令

```bash
# 全量刷机
luatos-cli flash run --soc firmware.soc --port COM10

# 全量刷机并覆盖脚本区
luatos-cli flash run --soc firmware.soc --port COM10 --script lua/

# 刷机后继续抓启动日志
luatos-cli flash run --soc firmware.soc --port COM10 --tail-log-secs 30

# 仅刷脚本区
luatos-cli flash script --soc firmware.soc --port COM10 --script lua/

# 查看二进制日志（建议带 probe）
luatos-cli log view-binary --port COM10 --baud 2000000 --probe

# 闭环验证
luatos-cli flash test --soc firmware.soc --port COM10 --timeout 15 --keyword "LuatOS@"

# 闭环验证（带脚本覆盖 + 自定义关键字）
luatos-cli flash test --soc firmware.soc --port COM10 --script lua_case_a --timeout 30 --keyword "CASE_A_ONLY_20260530"

# 闭环验证（快速判失败关键字）
luatos-cli flash test --soc firmware.soc --port COM10 --timeout 30 --keyword "CASE_A_ONLY_20260530" --fail-keyword "assert" --fail-keyword "panic"
```

## 说明

- Air1602 走 Air1601/CCM4211 同路径
- 日志协议为 SOC 二进制帧，建议使用 `log view-binary`
- `flash run --script` 会在全量刷机时用所选目录覆盖 SOC 包内自带脚本
- `flash test` 在本型号上如果传入 `--script`，会在全量刷机时覆盖脚本分区，再抓日志做关键字判定
- `--fail-keyword` 未传时不会触发快速判 FAIL；传入后命中任意关键字会立即 FAIL，减少等待时间
