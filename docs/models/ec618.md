# EC618 / Air780E / Air780EG

## 适用型号

- EC618
- Air780E / Air780EG
- 固件 `info.json` 中 `chip.type` 为 `ec618`

Air780EPM / Air780EHM 等 EC718 型号请参考 [EC7xx 型号文档](air8000-ec7xx.md)。

## 推荐命令

```bash
# 全量刷机，写入 Bootloader、AP、CP 和 SOC 自带脚本
luatos-cli flash run --soc firmware.soc --port auto

# 全量刷机并覆盖脚本目录
luatos-cli flash run --soc firmware.soc --port auto --script lua/ --luac-debug 99

# 仅刷脚本分区
luatos-cli flash script --soc firmware.soc --port auto --script lua/

# 写入已经编译好的 script.bin
luatos-cli flash script --soc firmware.soc --port auto --bin script.bin

# USB 二进制日志
luatos-cli log view-binary --port auto --baud 921600 --probe

# 刷机后验证本例自带脚本的输出；关键字应按实际脚本调整
luatos-cli flash test --soc firmware.soc --port auto --timeout 15 --keyword "hi, LuatOS"
```

## 进入下载模式

工具先尝试通过运行口发送 `AT+ECRST=delay,799` 与 DIAG 下载指令。是否成功取决于设备当前固件，串口写入成功不代表已进入下载模式。

如果没有出现下载口，请手动操作：

1. 按住 BOOT。
2. 按 RESET，或者重新上电。
3. 松开 BOOT。
4. 确认下载口出现，再运行刷机命令；`--port auto` 会直接使用它。

USB 标识：运行模式 `19D1:0001`，下载模式 `17D1:0001`。运行时 SOC 日志口为通信接口 2（部分系统上报其数据接口 3），不要按 COM 号排序猜测端口。

## 实机记录

Windows + Air780EG_A12，测试包 `helloworld_1.0.0_LuatOS-SoC_V1124_EC618_FULL.soc`：

- 免 BOOT 未成功，按上述步骤手动进入下载模式后识别为 COM6。
- SOC 自带 USB AgentBoot 为 35,676 字节。
- 全量刷机四个分区通过设备端校验，复位后运行口 COM3 恢复。
- 日志确认 `LuatOS-SoC_V1124_EC618_FULL`、`Air780EG_A12` 与持续 `hi, LuatOS`。
- release 版单独刷脚本通过，393 字节测试镜像持续输出 `EC618_SCRIPT_OK`。
- release 版 `flash test --keyword "hi, LuatOS"` 返回 PASS，JSONL 结果包含 `chip=ec618`、`missing_keywords=[]`；设备最终恢复 SOC 原始脚本。
- 过程中有一次 AP 写入阶段 USB 断连并重启，重新手动 BOOT 后用同一二进制复测通过，尚未确定该次复位原因。

可重复使用的 Lua 测试脚本见 [EC618 测试夹具](../../tests/ec618_test_script/README.md)。

具体协议与存储差异见 [EC618 刷机协议](../ec618-flash-protocol.md)。
